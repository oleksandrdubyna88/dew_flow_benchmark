# t5 — The consultant check on Kimi: a copy, a one-shot home, disposed junction-first

## Goal
`coai-mcp --check-consultant` (code: `ConsultantCheckMode.AnswerAsync` → `ConsultantCheck`) must run ONE Kimi turn the way a
consultation makes it: in a COPY of the check's scratch repository, on a one-shot owned home under `<homes root>\coai-vh\<8>\kh-<10 hex>`
(or, with no homes root, under `<scratch>\own\kh-<10 hex>`), disposed junction-first whatever ended the check (passed, failed with exit 70,
cancelled). The check's own invariant (the scratch repository unchanged, the canary untouched) holds. The production code is already in
place (E5.3 decision g for the disposal, E5.4 for `KimiConsultant`): this task ADDS TESTS that prove the path. It delivers S5.5.1–S5.5.4.
It depends on no other task of this run.
