# t4 — A Kimi `disk` question row through the service: copies named, everything disposed junction-first

## Goal
Prove, through the real `ask_consultants` flow (`PanelService.AskConsultantsAsync`) with git for real and the Kimi shim PLAYED
(`PlayedKimi`), that a Kimi question row on a `disk` prompt: stands in a COPY of its granted root, is told the copy's path and never the
root, and — on an answer, on a refusal before the launch and on a cancellation mid-turn — leaves nothing behind: the one-shot folder
`<homes root>\coai-vh\<8>` is gone, the deleter never met the home's junction (it was unlinked first), and the fake person's sign-in
folder is whole. Delivers S5.6.7. This task adds ONE new test file. No production code is expected to change. Tasks t1 (table) and t3
(planner arm, `KimiConsultant` on planned launches) are done in your starting tree.
