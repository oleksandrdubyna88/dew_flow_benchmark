## Goal

roots (`CwdKind.Snapshot`), a `none` row stands in an empty scratch folder (`CwdKind.Scratch`), neither carries any flag (Kimi's
confinement is the shim's, not its argv), and a `web` prompt is refused (the matrix already refuses it after t1). `KimiConsultant`
must build such a launch on the row's own one-shot home with no `--session`, and must refuse with `ArgumentException` a plan that
carries any flag or leading argument. Delivers S5.6.3, S5.6.5, S5.6.6. Task t1 (the table rows) is done in your starting tree.

In `Build` (`:47-56`), right after `ConsultantLaunches.MustBeLaunchable(launch);` add the call `MustCarryNoFlag(launch);` and add this private method (put it with the other private statics):
```csharp
/// <summary>A Kimi row's confinement is the shim's, so a plan with flags is not one coai made for kimi — refused by name, never sent.</summary>
private static void MustCarryNoFlag(ConsultantLaunch launch)
{
    if (launch.Confinement is LaunchConfinement.Planned { Plan: { Flags.Count: > 0 } or { Leading.Count: > 0 } })
    {
        throw new ArgumentException(
            "a Kimi row's confinement is the shim's; a plan with flags is not one coai made for kimi",
            nameof(launch));
    }
}
```
(You may write the condition as two `||` property tests if the pattern does not compile; keep cyclomatic complexity ≤ 4.)
