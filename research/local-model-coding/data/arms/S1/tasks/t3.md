Repository root: the clone you work in. Branch base: `b4e2ea96`. Depends on nothing (the Kimi consultant and E5.3's disposal are already in the code). Runs beside t1 and t2.

## Goal

`coai-mcp --check-consultant` runs one Kimi turn as a consultation makes it: in a COPY of the check's scratch repository
(`<scratch>\own\tree`), on a ONE-SHOT owned home (junction and all) `<homes root>\coai-vh\<8 hex>\kh-<10 hex>`, disposed
junction-first whatever ended the check (answer, failed turn, cancellation, no homes root). The check's own invariant (the scratch
repository unchanged, the canary untouched) holds.

Scenarios delivered: **S5.5.1, S5.5.2, S5.5.3, S5.5.4**.

**This is a tests-only task.** The check already has no Kimi branch: it gives a copy to a runtime whose `NeedsASanitisedSnapshot`
is true and a one-shot home to a runtime whose `HomesFolder` is not empty (`ConsultantCheck.cs:211`, `:230-233`), and
`KimiConsultant` declares both. Do NOT change any production file. If a test shows a real fault in production code, STOP and
report it (file, line, assertion message).
