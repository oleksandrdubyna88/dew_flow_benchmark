## Goal

A question-consultant row that runs on Kimi launches through `KimiConsultant.Build` with a PLANNED confinement (a `none` row in an
empty folder, a `disk` row in the copy of its roots, one-shot, no `--session`, on the row's one-shot home). A plan that carries
any flag is refused with `ArgumentException`, because Kimi's confinement is the shim's and no plan of coai's carries a flag for it.
The whole row, through `PanelService.AskConsultantsAsync`, leaves nothing behind on an answer, a refusal or a cancellation: the row's
scratch and `coai-vh\<8>` are gone, the deleter never met the junction, the person's folder is whole.

```csharp
/// <summary>
/// Kimi's confinement is the shim's (D15), never its argv — so a plan that carries a flag (leading, trailing or an added directory) is not
/// one coai made for kimi, and nothing of it is sent (E5.6 decision 3).

private static void MustCarryNoFlagsOfAPlan(ConsultantLaunch launch)
{
    if (launch.Confinement is LaunchConfinement.Planned { Plan: { } plan } && (plan.Leading.Count > 0 || plan.Flags.Count > 0 || plan.AddDirs.Count > 0))

        throw new ArgumentException("a Kimi row's confinement is the shim's; a plan with flags is not one coai made for kimi", nameof(launch));
    }
}
```
