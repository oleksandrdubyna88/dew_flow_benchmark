## Goal
`ConfinementPlanner.Plan("kimi", …)` plans a `none` row in an EMPTY scratch folder and a `disk` row in a coai-made COPY of its
roots (`CwdKind.Snapshot`, `SnapshotSources` = the roots), with NO flags and no added directories, both flagged
`AdmissionFlag.Unconfined` (from the matrix); `web` is refused by the matrix before the arm. Delivers **S5.6.3** (E5.6 decision 1).

```csharp
    /// <remarks>
    /// No flags, ever: Kimi's confinement is the shim's (D15 of todo/PLAN_vibe_and_kimi_runtimes.md), not its argv, so the plan carries none and
    /// <see cref="SandboxVocabulary"/> gains nothing. Kimi loads its configuration from its working folder (M-K9 (e)), so a disk row's roots are
    /// COPIED into the snapshot it stands in (D6); a none row stands in an empty folder — which bounds <c>Read</c> only (M-K6), hence the flag.
    /// </remarks>
    private static Confinement.Planned Kimi(CapabilityGrant grant, AdmissionFlag flag) => grant.Capability switch
    {
        Capability.Disk => new("kimi", grant, [], [], CwdKind.Snapshot, [], flag) { SnapshotSources = grant.Roots },
        // `web` never reaches here: the matrix refuses it (no Kimi cell exercises WebSearch or FetchURL).
        _ => new("kimi", grant, [], [], CwdKind.Scratch, [], flag),
    };
```
