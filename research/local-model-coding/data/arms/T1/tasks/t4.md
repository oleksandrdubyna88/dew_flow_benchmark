# t4 — The consultant check (`--check-consultant`) for Kimi: a copy, a one-shot home, disposed junction-first

Read first: `/home/jinx/git/coai-exp/vllm/work/T1/common.md`. Spec: E5.5 in `todo/PLAN_vibe_and_kimi_runtimes_E5.md`. Depends on nothing.

## Goal
Prove, with the played shim, that `coai-mcp --check-consultant` on a Kimi row runs one turn as a consultation makes it: in a COPY of
the check's scratch repository (`<scratch>/own/tree`), on a ONE-SHOT owned home `<homes root>/coai-vh/<8>/kh-<10 hex>` (or, with no
homes root, `<scratch>/own/kh-<10 hex>`), disposed junction-first however the check ended. Delivers **S5.5.1–S5.5.4**.
**Production code is NOT in this task** (E5.5 decision 1: no new branch in the check — E5.4 and E5.3 g already built the path).
These four tests are expected GREEN once written; each must still be seen to fail ONCE on purpose (Steps) so it is known to bite.
