# t5 — A Kimi `disk` question row through the service: reads its copies, leaves nothing behind

Read first: `/home/jinx/git/coai-exp/vllm/work/T1/common.md`. Spec: E5.6 in `todo/PLAN_vibe_and_kimi_runtimes_E5.md` (scenario S5.6.7,

## Goal
`ask_consultants` with one enabled Kimi row on a `disk` prompt runs through `QuestionRowLaunch` with the played shim: the prompt
names the COPIES of the granted roots and never the root; however the row ends — answered, refused before the launch, cancelled
mid-turn — the row's copy and its one-shot `coai-vh/<8>` folder are gone, the deleter's unlink recorder is never invoked
(the home is disposed junction-first), and the fake person's folder is whole. Delivers **S5.6.7**. No production change
(decision 5: `QuestionRowLaunch`'s reservation, place and `finally` are generic).

Body, in order:
1. `using var standIn = StandIn(); var before = _person.Hash(); GitScratch.AfterUnlink = _unlinkedByTheDeleter.Add;`
   `var granted = Path.Combine(Repo, "src");`
   `using var caller = CancellationTokenSource.CreateLinkedTokenSource(TestContext.Current.CancellationToken);`
2. The played shim: `var played = new PlayedKimi(_launcher) { Turn = static (_, request) => PlayedKimi.Answered(PlayedKimi.SessionOf(request), 1200, 40), During = ending == Ending.CancelledMidTurn ? async (_, ct) => { await caller.CancelAsync(); ct.ThrowIfCancellationRequested(); } : static (_, _) => Task.CompletedTask };`
3. `RefusedBeforeTheLaunch`: `File.Delete(_person.Credentials);` before asking — the launch control refuses a person with no sign-in
   (D19), so no shim starts.
4. Ask: for `CancelledMidTurn`: `var asking = async () => await AskAsync(Service(played, granted), caller.Token); await asking.Should().ThrowAsync<OperationCanceledException>();`
   otherwise `var reply = await AskAsync(Service(played, granted));` and
   `TheRow(reply).GetProperty("status").GetString().Should().Be(ending == Ending.Answered ? RowOutcomes.Answered : RowOutcomes.Failed, reply.ToString());`
5. Launches: `RefusedBeforeTheLaunch` → `played.Shims.Should().BeEmpty("the launch control refused before any shim started")`.
   The other two → `var request = played.Shims.Should().ContainSingle().Subject.Request;` and:
   - `request.StdIn.Should().Contain(request.WorkingDirectory, "the prompt names the copies, under the row's tree")`;
   - `request.StdIn.Should().NotContain(granted, "never the root (D6)")`;
   - `request.Arguments.Should().NotContain(argument => argument.Contains(Repo), "neither root nor checkout on the argv")`;
   - `Directory.Exists(request.WorkingDirectory).Should().BeFalse("the row's copy is gone")`;
   - `var home = request.Arguments[request.Arguments.ToList().IndexOf(AcpWords.HomeFlag) + 1];`
     `Path.GetDirectoryName(Path.GetDirectoryName(home)!).Should().Be(OneShotRoot, "the row's home under the homes root's coai-vh (deviation 3)")`.
6. For every ending: `(!Directory.Exists(OneShotRoot) || !Directory.EnumerateFileSystemEntries(OneShotRoot).Any()).Should().BeTrue("coai-vh/<8> is gone")`;
   `_unlinkedByTheDeleter.Should().BeEmpty("the deleter's unlink recorder must not be invoked, because KimiHome unlinks the junction first")`;
   `_person.Hash().Should().Equal(before, "the person's folder: the same names, bytes and read-only bits")`.
