## Goal

A question-consultant row on Kimi with a `disk` prompt: the prompt names the COPIES of the granted roots (never the roots), the shim stands in the row's copy, the home is a one-shot home under
`<homes root>\coai-vh\<8 hex>\kh-<10 hex>`, and after EACH way the row ends (answered, refused before the launch, cancelled mid-turn) the row's scratch folder and `coai-vh\<8>` are gone, the deleter's unlink
recorder was never invoked (junction-first disposal), and the fake person's folder is whole. **The plan says no production code is needed** (E5.6 decision 5): `QuestionRowLaunch`'s reservation, place and `finally` are generic and the
disposal is E5.3's. This task is a TEST that proves it. Delivers **S5.6.7**.
