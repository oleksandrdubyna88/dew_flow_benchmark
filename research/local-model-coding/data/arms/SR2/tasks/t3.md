## Goal

`coai-mcp --check-consultant` for a Kimi row runs one turn as a consultation does: in a COPY of the check's scratch repository, on a ONE-SHOT owned
home under `<homes root>\coai-vh\<8 hex>\kh-<10 hex>` (a junction to the person's sign-in inside), and the home is disposed junction-first whatever
ended the check. The check's own invariant (the scratch repository and the canary unchanged) holds. **The plan says no production code is needed**
(E5.5 decision 1): the check already gives a copy to a runtime that asks (`NeedsASanitisedSnapshot`) and a one-shot home to a runtime that declares a
`HomesFolder`, and `KimiConsultant` does both. So this task is TESTS that prove that path. Delivers **S5.5.1, S5.5.2, S5.5.3, S5.5.4**.
