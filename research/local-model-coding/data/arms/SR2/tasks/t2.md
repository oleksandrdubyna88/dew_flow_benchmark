### 2. `KimiConsultant.cs`

In `Build`, directly after `ConsultantLaunches.MustBeLaunchable(launch);` add the call `MustCarryNoFlags(launch);` and add the method (complexity ≤ 4):

```csharp
/// <summary>A plan that carries ANY flag is not one coai made for kimi: its confinement is the shim's, never its argv (E5.6 decision 3).</summary>
private static void MustCarryNoFlags(ConsultantLaunch launch)
{
    if (launch.Confinement is LaunchConfinement.Planned { Plan: var plan } && plan.Leading.Count + plan.Flags.Count + plan.AddDirs.Count > 0)
    {
        throw new ArgumentException(
            "a Kimi row's confinement is the shim's; a plan with flags is not one coai made for kimi", nameof(launch));
    }
}
```

(If `Plan` is not the property name, read how `ConsultantLaunches.MustBeLaunchable` reads the plan from `launch.Confinement` and use that.)
Also update the class summary line of `KimiConsultant` with one sentence: "A planned (question) launch is one shot and carries no flag (E5.6)." Nothing else changes.
