# t2 — The planner's `kimi` arm, and `KimiConsultant` refuses a planned launch with flags

Repository: the clone at `b4e2ea96` plus the merged result of **t1** (Kimi's three capability rows, `RuntimeCapabilities.Runtimes`
gains `kimi`). Spec: `todo/PLAN_vibe_and_kimi_runtimes_E5.md`, section **E5.6**, decisions 1 and 3, scenarios S5.6.3, S5.6.5, S5.6.6.
Read only this document and the files it names.

## Goal

A question-consultant row on Kimi gets a plan from the ONE planner: a `disk` grant stands in a COPY of its roots
(`CwdKind.Snapshot`, `SnapshotSources` = the roots), a `none` grant stands in an empty folder (`CwdKind.Scratch`). The plan
carries NO flags, because Kimi's confinement is the shim's (D15), not its argv. A `web` grant never reaches the arm: the matrix
refuses it (t1's `unmeasured` row). `KimiConsultant.Build` refuses a planned launch whose plan carries any flag, with an
`ArgumentException` that names the shim. Scenarios: **S5.6.3, S5.6.5, S5.6.6**.

**Depends on t1.** `ConfinementPlanner.Plan` asks `CapabilityMatrix.Admit` FIRST (`ConfinementPlanner.cs:105-117`). Without t1's rows
every `kimi` plan is `Refused` ("'kimi' is not a runtime the question consultant can launch …") and no arm is reached.

Add this private method directly after `Build`:

```csharp
    /// <summary>
    /// E5.6 decision 3: a Kimi row's confinement is the shim's, so the planner's kimi arm gives a plan no flags — one that carries any
    /// (<see cref="Confinement.Planned.Leading"/> or <see cref="Confinement.Planned.Flags"/>) was not made by coai for kimi, and is refused before anything is built.
    /// </summary>
    private static void MustCarryNoPlannedFlag(ConsultantLaunch launch)
    {
        if (launch.Confinement is LaunchConfinement.Planned { Plan: var plan } && plan.Leading.Count + plan.Flags.Count > 0)
        {
            throw new ArgumentException("a Kimi row's confinement is the shim's; a plan with flags is not one coai made for kimi", nameof(launch));
        }
    }
```
