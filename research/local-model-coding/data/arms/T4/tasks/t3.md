## Goal

Prove that `coai-mcp --check-consultant` runs one Kimi turn the way a consultation makes it: in a COPY of the check's scratch
repository (`<scratch>/own/tree`), on a ONE-SHOT owned home `<homesRoot>/coai-vh/<8>/kh-<10 hex>`, and that the home is
disposed junction-first however the check ends (passed, failed with exit 70, cancelled, and with no homes root). **This task
adds tests only.** E5.5 decision 1: the check needs no new branch — `KimiConsultant` (E5.4) declares `NeedsASanitisedSnapshot`
and `HomesFolder`, and E5.3 decision g made the one-shot disposal junction-first. Scenarios: **S5.5.1, S5.5.2, S5.5.3, S5.5.4**.

**S5.5.3** `public async Task ACheckCancelledMidTurn_StillDisposesItsHome()`

```csharp
using var stop = CancellationTokenSource.CreateLinkedTokenSource(TestContext.Current.CancellationToken);
var started = new TaskCompletionSource<string>(TaskCreationOptions.RunContinuationsAsynchronously);
var played = new PlayedKimi(new ProcessLauncher())
{
    During = async (request, ct) =>
    {
        started.TrySetResult(ValueOf(request, AcpWords.HomeFlag));
        await Task.Delay(Timeout.Infinite, ct);
    },
};
GitScratch.AfterUnlink = _unlinkedByTheDeleter.Add;
var checking = Check(Settings(homes), played, stop.Token);
var home = await started.Task.WaitAsync(TimeSpan.FromSeconds(60), TestContext.Current.CancellationToken);
Directory.Exists(home).Should().BeTrue("the home is there while the turn runs");
await stop.CancelAsync();
var (_, said, _) = await checking;

Text(said, "state").Should().Be(ConsultCheckStates.Failed, said.ToString());

_unlinkedByTheDeleter.Should().BeEmpty("junction-first on a cancel too");
person.Hash().Should().Equal(before);
```
