# t4 — The consultant check for Kimi (S5.5.1–S5.5.4)

Repository: the clone at `b4e2ea96` (E5.3 and E5.4 are in). Spec: `todo/PLAN_vibe_and_kimi_runtimes_E5.md`, **E5.5** (read it; it is short).

## Goal

Prove that `coai-mcp --check-consultant` runs one Kimi turn as a consultation makes it: in a COPY of the check's scratch repository
(`<scratch>/own/tree`), on a ONE-SHOT home `<homes root>/coai-vh/<8>/kh-<10 hex>` — or, with no homes root, `<scratch>/own/kh-<10 hex>` —
and that the home is disposed junction-first however the check ended (answered, failed exit 70, cancelled). **Decision 1: no new branch in the
check.** This task writes a test class; it changes `ConsultantCheck.cs` / `ConsultCheckScratch.cs` ONLY if a scenario is red for a production
reason (then the smallest fix, written in the summary). Decision 3: the check's recorded `confinement` for Kimi is empty, as Vibe's — asserted
below. Delivers **S5.5.1, S5.5.2, S5.5.3, S5.5.4**.
