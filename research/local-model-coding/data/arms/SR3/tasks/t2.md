## Goal

`ConfinementPlanner.Plan("kimi", …)` answers a real plan: `none` stands in an empty scratch folder, `disk` stands in a COPY of its
roots, both with NO flags (Kimi's confinement is the shim's, D15, not its argv), both flagged `Unconfined`; `web` is refused by
the matrix. `KimiConsultant.Build` takes a planned (question-row) launch, and refuses a plan that carries any flag. Scenarios:
**S5.6.3, S5.6.5, S5.6.6**.

  ```csharp
  /// NO flags, ever (E5.6 decision 1): Kimi's confinement is the shim's (D15), not its argv, so the plan carries none and
  /// <see cref="SandboxVocabulary"/> gains nothing. Kimi reads through its working folder only for <c>Read</c> (M-K6), so a disk row's
  /// roots are COPIED into the snapshot it stands in (D6, M-K9 (e): a branch's AGENTS.md, skills, sub-agents and .mcp.json load from

      // `web` never reaches here: the matrix refuses it (no Kimi cell exercises the web).

  };
  ```

  ```csharp
  /// <summary>A planned launch carries none of the sandbox fragments the planner gives other runtimes: Kimi's confinement is the shim's (E5.6 decision 3).</summary>
  private static void MustCarryNoPlanFlags(ConsultantLaunch launch)
  {
      if (launch.Confinement is LaunchConfinement.Planned { Plan: { } plan } && plan.Flags.Concat(plan.Leading).Concat(plan.AddDirs).Any())
      {
          throw new ArgumentException(
              "a Kimi row's confinement is the shim's; a plan with flags is not one coai made for kimi", nameof(launch));
      }
  }
  ```
