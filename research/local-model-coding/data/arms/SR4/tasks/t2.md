# t2 — The planner's Kimi arm, and KimiConsultant's refusal of a plan with flags

Repository root: the clone. You read ONLY this document and the files it names. Do not commit. Do not edit any file not listed under *Files*.
Depends on **t1** (the `kimi` rows in the capability table): `ConfinementPlanner.Plan` asks `CapabilityMatrix.Admit` first, so before t1 `Plan("kimi", …)` is `Refused`.

## Goal

A question-consultant row on Kimi gets a plan: `disk` → a copy of the granted roots (`CwdKind.Snapshot`), `none` → an empty folder (`CwdKind.Scratch`), NO flags ever
(Kimi's confinement is the shim's, not its argv). `web` is refused by the matrix (t1). `KimiConsultant.Build` on a planned launch stands in the plan's cwd, on the
row's home, with no `--session`, and REFUSES a plan that carries any flag. Delivers S5.6.3, S5.6.5, S5.6.6 (plan E5.6 decisions 1 and 3).

```csharp
    /// <remarks>
    /// Kimi's confinement is the coai shim's (D15), never its argv, so the plan carries no flag and no leading argument, ever. A disk row's roots are COPIED
    /// into the snapshot it stands in (`Read` is bounded to its working folder, M-K6; a branch's AGENTS.md, skills, sub-agents and .mcp.json load from disk,
    /// M-K9 (e)); a none row stands in an empty folder. Both rows are `unconfined` (`Grep` and `Glob` read the disk), which the matrix admits FLAGGED.
    /// </remarks>
    private static Confinement.Planned Kimi(CapabilityGrant grant, AdmissionFlag flag) => grant.Capability switch
    {
        Capability.Disk => new("kimi", grant, [], [], CwdKind.Snapshot, [], flag) { SnapshotSources = grant.Roots },
        // `web` never reaches here: the matrix refuses it (no Kimi cell exercises the web).
        _ => new("kimi", grant, [], [], CwdKind.Scratch, [], flag),
    };
```
