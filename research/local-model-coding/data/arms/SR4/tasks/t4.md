Repository root: the clone. You read ONLY this document and the files it names. Do not commit. Do not edit any file not listed under *Files*.

## Goal

`coai-mcp --check-consultant` for a Kimi row runs one turn as a consultation makes it: in a COPY of the check's scratch repository, on a ONE-SHOT home
(`<homes root>\coai-vh\<8 hex>\kh-<10 hex>`), disposed junction-first whatever ended the check (answer, failed turn, cancellation), and, with settings that have no homes root,
on `<scratch>\own\kh-<10 hex>` disposed junction-first with the scratch. The check's own invariant (the scratch repository and the canary unchanged) holds.
Delivers S5.5.1–S5.5.4 (plan E5.5). **No production code**: the check already gives a copy to a runtime that asks (`NeedsASanitisedSnapshot`) and a one-shot home to a
runtime that declares a `HomesFolder`; both are `true` for `KimiConsultant`. This task proves the path with four tests.
