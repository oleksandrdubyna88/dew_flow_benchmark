Repository root: the clone. You read ONLY this document and the files it names. Do not commit. Do not edit any file not listed under *Files*.

## Goal

Prove, through the real `ask_consultants` flow (`PanelService.AskConsultantsAsync`), git for real and the Kimi shim PLAYED, that a `disk` question-consultant row on Kimi
(a) stands in a COPY of its granted roots and its prompt names the copies, never the roots; (b) keeps its home in a one-shot folder under `<homes root>\coai-vh\<8>`;
(c) after each ending — answered, refused before the launch, cancelled mid-turn — has no scratch and no `coai-vh\<8>` left, the junction was unlinked FIRST (the deleter's
recorder never invoked), and the fake person's sign-in folder is intact. Delivers S5.6.7 (plan E5.6 decision 5: "nothing new in `QuestionRowLaunch`").
This task writes ONE new test file and no production code.
