# Group brief — adversarial

Questions built to be answered WRONG by a model working from memory rather than from the repository.

Every other group tries to be fair. This one tries to discriminate: its whole purpose is that a subject which
never retrieved anything scores badly, so that a high baseline score is visible as memorisation instead of
being mistaken for competence.

- The question's obvious answer must be the widely repeated one, and the correct answer in THIS repository
  must differ. That gap is the question.
- **An `AnswerExcludes` expectation is mandatory here**, naming the term the memorised answer would use.
- Good sources of the gap: a well-known pattern implemented unusually, a default that differs from the
  library's documented one, a name that means something else here than it does elsewhere.
- Do not build the gap out of a typo or a triviality. A question whose trap is a spelling difference measures
  attention, not knowledge.
